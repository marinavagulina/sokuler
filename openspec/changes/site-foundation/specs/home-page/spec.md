# Spec Delta: home-page

## Purpose

Главная страница — точка входа: первый экран с позиционированием и целевыми действиями (запись на занятие, афиша) плюс полоса фактов. Структура следует утверждённому референсу johnpatitucci.com; сайт позиционируется как «фундаментальный архив», а не лента.

## ADDED Requirements

### Requirement: Первый экран с позиционированием и CTA
Система SHALL отображать на первом экране главной: надзаголовок «Контрабас · бас-гитара · педагог», имя «Сергей Сокулер», подзаголовок-рукопись (Gabriola), лид с позиционированием «Меньше — но качественнее», две кнопки («Записаться на занятие» — основная, «Афиша концертов» — вторичная) и строку подписки на анонсы.

#### Scenario: Целевые действия первого экрана
- **WHEN** пользователь открывает главную страницу
- **THEN** видит обе кнопки и может перейти по ним (страницы-приёмники подключаются следующими изменениями, до тех пор ссылки ведут на якоря-заглушки)

#### Scenario: Подписка на анонсы
- **WHEN** пользователь нажимает «оставить почту»
- **THEN** открывается поле ввода email (отправка формы реализуется следующим изменением)

### Requirement: Визуальный блок первого экрана
Система SHALL отображать справа на первом экране рамку под портрет (4:5, плейсхолдер с линейным силуэтом контрабаса и подписью «Фото · фотосессия») до получения фотографий с фотосессии.

#### Scenario: Плейсхолдер до фотосессии
- **WHEN** фотографии ещё не загружены в `public/img/`
- **THEN** в рамке отображается декоративный силуэт и подпись, вёрстка не ломается

### Requirement: Полоса фактов
Система SHALL отображать под первым экраном три факта: «Преподаю с 2004 года», «Контрабас и бас-гитара», «Ученикам» — с краткими пояснениями.

#### Scenario: Факты видны без прокрутки меню
- **WHEN** пользователь прокручивает первый экран
- **THEN** под ним видна полоса из трёх фактов, на мобильных — в один столбец

### Requirement: Метаданные главной для поиска
Система SHALL задавать странице title «Сергей Сокулер — бас-гитара и контрабас» и description с упоминанием обучения, концертов и записей на русском языке.

#### Scenario: Поисковые сниппеты
- **WHEN** поисковая система формирует сниппет главной
- **THEN** title и description соответствуют заданным текстам
