# Design: site-foundation

## Context

Проект: статический сайт-архив на Astro 5 + Vue (сборка вручную, `output: 'static'`, strict TS). Утверждённые артефакты: мокапы `мокап-главная.html` и `мокап-главная-gabriola.html`, комплект логотипов `D:\Marina\Work\Maksimov-sokuler\logo\` (SVG в кривых, самодостаточные). Открытый вопрос с ограничением: диск C: почти пуст — всё тяжёлое держим на D: (npm-префикс и кэш уже перенаправлены).

## Goals / Non-Goals

**Goals**
- Воспроизвести утверждённый вид мокапа в компонентах Astro без визуальных отступлений.
- Заложить токены так, чтобы тёмные и светлые страницы смешивались без дублирования стилей.
- Подключить локальные шрифты (woff2) с корректным `font-display: swap`.

**Non-Goals**
- Формы с отправкой (следующее изменение), CMS, интерактивные каталоги (Vue-острова позже).
- Тёмная/светлая тема-переключатель — тема задаётся страницей, не пользователем.
- Оптимизация картинок под photо — фото ещё нет.

## Decisions

1. **Токены — один файл `src/styles/tokens.css` + `base.css`, импорт в `Base.astro`.**
   Альтернатива: CSS-модули/Tailwind — отвергнуто: для сайта-архива хватит custom properties, нулевая зависимость, полный контроль.
2. **Логотип — инлайн SVG в компоненте Header.**
   Альтернатива: `<img src>` — отвергнуто для шапки: инлайн позволяет управлять размером одним параметром и не даёт вспышки при загрузке; файлы-первоисточники остаются в `public/logo/` для скачивания и фавикона.
3. **Шрифты — сабсет woff2 в `public/fonts/`, `@font-face` в base.css.**
   Альтернатива: Google Fonts CDN — отвергнуто по спеке (нет внешних запросов) и по скорости (RFC-запрос в рантайме). Сабсеты делаем pyftsubset (fonttools уже установлен) — кириллица + латиница базовая.
4. **Разделение цветовых тем — через `data-theme="dark|light"` на `<body>`.**
   Токены объявляются дважды: `:root` (light) и `[data-theme="dark"]`; главная получает dark. Альтернатива: два набора классов — отвергнуто: тема на корне проще и наследуется.
5. **Соцсети — константа в `src/config.ts`.**
   Альтернатива: держать в разметке футера — отвергнуто по спеку (смена адреса без правки компонентов).

## Risks / Trade-offs

- [Сабсеты шрифтов могут не покрыть редкие символы в будущих постах] → включаем в сабсет полный кириллический диапазон + пунктуацию; фолбэк на системный serif/sans.
- [Инлайн-SVG логотипа дублируется в шапке и фавиконе] → первоисточник один (`public/logo/logo-шапка-тёмный.svg`), инлайн генерируется на сборке из файла, не руками.
- [Мокап ≠ финальная вёрстка на живых экранах] → сравнение в браузере на 1440/1024/375, мелкие отклонения согласуем скриншотами.
