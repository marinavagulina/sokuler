# Proposal: site-foundation

## Why

Сайт Сергея Сокулера переходит от мокапов к реализации. Нужен визуальный и структурный фундамент: утверждённая палитра «фиолетовый + бронза», типографика, шапка с логотипом и первый экран главной страницы. Без этого слоя каждая следующая страница (Обучение, Афиша, EPK) будет собираться «на глазок» и разъезжаться стилями.

## What Changes

- Вводится система дизайн-токенов (CSS custom properties): палитра, типографика, отступы — единственный источник правды для всех страниц.
- Токены переносятся из утверждённого мокапа `мокап-главная-gabriola.html` (палитра совпадает с `мокап-главная.html`).
- Появляется шапка сайта (Header): логотип-локап Gabriola (SVG в кривых) + меню разделов + кнопка «Контакты».
- Появляется футер (Footer): контакты, ссылки на соцсети (ВК, YouTube — отображаемое имя «Басист Сергей Сокулер»), копирайт.
- Главная страница собирается по структуре референса johnpatitucci.com: первый экран (имя, позиционирование, 2 CTA), полоса фактов; остальные разделы — следующие изменениями.
- Шрифты подключаются локально (Playfair Display, Inter, Gabriola) — без запросов к Google Fonts в рантайме.

## Capabilities

### New Capabilities

- `design-tokens`: палитра, типографика, spacing — договорённости о визуальном языке, на которые опираются все страницы.
- `site-chrome`: шапка (логотип, меню, CTA) и футер (контакты, соцсети, копирайт) — общий каркас всех страниц.
- `home-page`: первый экран главной и полоса фактов — точка входа по структуре Патитуччи.
