# Афиша концертов — как Сергею редактировать самому

## Один раз настраивает Марина (10 минут)

1. Создать Google-таблицу: https://sheets.new
2. Назвать её «Афиша — сайт sokuler.ru»
3. В первой строке сделать заголовки (ровно такими словами):

   | дата | город | площадка | что | билеты |
   |------|-------|----------|-----|--------|

4. Добавить пример-строку (потом Сергей заменит реальными):
   ```
   15.02.2027 | Москва | Градский-холл | «Вальс-Бостон» | https://...
   ```
5. Файл → «Поделиться» → «Все, у кого есть ссылка» → **Просмотр**
6. Скопировать ссылку и превратить её в ссылку экспорта CSV:
   - была: `https://docs.google.com/spreadsheets/d/ВАЖНЫЙ_КОД/edit?...`
   - нужна: `https://docs.google.com/spreadsheets/d/ВАЖНЫЙ_КОД/export?format=csv`
7. Задать ссылку как секрет репозитория:
   - GitHub → sokuler → Settings → Secrets and variables → Actions
   → New repository secret → имя `CONCERTS_SHEET_URL`, значение — CSV-ссылка
8. Нажать «Run workflow» на вкладке Actions (или подождать час —
   пересоберётся сама)
9. Дать Сергею ссылку на таблицу с правом редактирования.

## Что делает Сергей (каждый раз)

Открывает таблицу, добавляет/правит строки:
- **дата** — ДД.ММ.ГГГГ (например 15.03.2027)
- **город** — например «Москва» (можно оставить пустым)
- **площадка** — например «Градский-холл»
- **что** — например «Вальс-Бостон», мюзикл
- **билеты** — ссылка на билеты (если есть; можно пусто)

Больше ничего не нужно: сайт в течение часа сам обновит страницу
«Концерты». Прошедшие концерты исчезают с сайта автоматически.

## Как это устроено (техника)

- `src/data/concerts.ts` — чтение таблицы при сборке (CSV), парсинг
  дат ДД.ММ.ГГГГ, фильтр прошедших, сортировка от ближних.
- `src/pages/koncerty.astro` — список концертов; при пустой таблице —
  заглушка «здесь появится афиша».
- `.github/workflows/deploy.yml` — ежечасный cron + пересборка при
  каждом пуше; URL таблицы берётся из секрета CONCERTS_SHEET_URL.
- Локальная сборка без .env не ломается (тоже заглушка).
