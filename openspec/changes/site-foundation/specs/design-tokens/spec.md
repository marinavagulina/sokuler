# Spec Delta: design-tokens

## Purpose

Единый визуальный язык сайта: палитра «фиолетовый + бронза», типографика и отступы как CSS custom properties. Все страницы обязаны брать цвета и шрифты из токенов — это гарантирует согласованность и позволяет менять тему в одном месте.

## ADDED Requirements

### Requirement: Палитра сайта задаётся токенами
Система SHALL определять фирменную палитру как CSS custom properties в едином файле токенов: основа тёмная `#2B1B3D`, фиолетовый акцент `#5B3A8E`, бронза `#B08D57`, светлая бронза `#D4B483`, светлый фон `#F7F4EF`, текст на светлом `#2A2438`, приглушённый текст на тёмном `#CFC4E0`.

#### Scenario: Цвета берутся из токенов
- **WHEN** любой компонент использует фирменный цвет
- **THEN** он ссылается на CSS-переменную токенов, а не на литеральный HEX

#### Scenario: Смена темы в одном месте
- **WHEN** изменяется значение токена в файле токенов
- **THEN** новый цвет применяется на всех страницах без правки компонентов

### Requirement: Типографика задаётся токенами
Система SHALL определять шрифтовые семейства (заголовки — Playfair Display, текст — Inter, акцент/рукопись — Gabriola) и масштаб кеглей как токены; шрифты SHALL поставляться локально из `public/fonts/` без обращения к внешним CDN.

#### Scenario: Страница не обращается к внешним шрифтовым CDN
- **WHEN** страница загружается
- **THEN** все шрифтовые файлы запрашиваются с домена самого сайта

#### Scenario: Рукописный акцент Gabriola доступен
- **WHEN** компоненту нужен рукописный стиль (акценты, цитаты)
- **THEN** он использует токен семейства Gabriola с корректным фолбэком на курсивный serif

### Requirement: Отступы и ритм задаются токенами
Система SHALL определять масштаб горизонтальных и вертикальных отступов как токены spacing, используемые компонентами вместо произвольных значений.

#### Scenario: Консистентные отступы
- **WHEN** компонент задаёт внешний или внутренний отступ
- **THEN** значение выбирается из шкалы spacing-токенов

### Requirement: Гигиена ассетов и стилей
При любом изменении неиспользуемые файлы и стили SHALL удаляться в том же изменении: шрифты без `@font-face`/ссылок, `@font-face` без используемых файлов, CSS-классы без элементов, изображения без `<img>`/`background`, компоненты без страниц. «Оставить на потом» SHALL не допускается.

#### Scenario: Удаление или замена элемента подчищает хвосты
- **WHEN** шрифт, изображение, компонент или класс удаляется либо заменяется другим
- **THEN** связанный файл из `public/`, декларация `@font-face`, CSS-правило или импорт удаляются в этом же изменении

#### Scenario: Проверка после чистки
- **WHEN** изменение затрагивает шрифты, стили или ассеты
- **THEN** перед завершением выполняются grep на оставшиеся ссылки на удалённые файлы и `npm run build`, и оба проходят без упоминаний удалённых файлов

#### Scenario: Замена версии файла
- **WHEN** файл (например, woff2) перезаписывается новой версией
- **THEN** старых дублей и неиспользуемых вариантов в `public/` не остаётся
